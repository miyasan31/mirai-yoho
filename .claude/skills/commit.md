# コミット

変更内容を分析して適切なコミットメッセージを生成し、git commit を実行してください。

## 手順

1. `git status` と `git diff`（staged + unstaged）を確認する
2. `git log --oneline -10` で直近のコミットメッセージのスタイルを確認する
3. 引数にメッセージが指定されている場合はそれを使用する
4. 指定がない場合は変更内容から日本語のコミットメッセージを生成する
5. 変更ファイルをステージングする（機密ファイルは除外）
6. コミットを実行する

## コミットメッセージのフォーマット

```
<prefix>: <変更内容の要約（日本語）>
```

### prefix ルール

- `feat`: 新機能
- `fix`: バグ修正
- `refactor`: リファクタリング
- `docs`: ドキュメント
- `test`: テスト
- `chore`: 依存関係やビルド設定の変更
- `style`: フォーマットやスタイルの変更

## ルール

- `.env`, `credentials.json` などの機密ファイルはコミットしない
- コミットメッセージは日本語で簡潔に書く
- Co-Authored-By を末尾に付ける
