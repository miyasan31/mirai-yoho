# みらい予報 - 業界展開分析

## システムのコア機能

「みらい予報」の本質を抽象化すると、以下の5つのコア機能で構成されている。

| コア機能               | 実装                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| **予約・スケジュール管理** | スロット制、ブロック時間、24時間キャンセルポリシー                |
| **ビデオ相談**           | Zoom + ブレイクアウトルーム（1日1ミーティング、コンサルタント別ルーム） |
| **決済**               | Stripe（カード登録・オフセッション課金）、バッチ課金               |
| **専門家管理**           | プロフィール、専門分野、稼働状態、メモ                            |
| **管理ダッシュボード**     | KPI、アカウント管理、ロールベースアクセス制御                       |

## 展開可能な業界と必要な機能の足し引き

### 1. オンライン医療・メンタルヘルス（遠隔診療）

**適合度: ★★★★★（非常に高い）**

現在のシステムとの親和性が最も高い業界。「専門家を選ぶ → 予約 → ビデオ通話 → 決済」のフローがそのまま活きる。

| 追加すべき機能                     | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| 電子カルテ連携（FHIR等）          | 診療記録の法的要件                             |
| 問診票（事前フォーム）             | consultationContent を拡張し、構造化された問診に |
| 処方箋発行・薬局連携               | オンライン診療の出口として必須                 |
| リピート予約・定期予約             | 慢性疾患の定期受診に対応                       |
| 録画・同意管理                     | 医療法上の記録保持義務                         |

| 削除・簡素化できる機能             | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| PayPay即時決済                     | 保険診療では不要（自費診療なら残す）           |
| specialties の自由入力             | 診療科マスタに置き換え                         |

**市場機会**: 日本のオンライン診療市場は急成長中。特にメンタルヘルス（カウンセリング）領域は保険外が多く、現状の決済フローと相性が良い。

### 2. 法律・税務・士業相談

**適合度: ★★★★★（非常に高い）**

弁護士・税理士・司法書士・社労士などの士業向けオンライン相談プラットフォーム。

| 追加すべき機能                     | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| ファイル共有（秘密保持付き）       | 契約書・申告書のやりとり                       |
| 相談カテゴリ分類                   | 離婚、相続、労務問題等のルーティング           |
| 相談時間の従量課金                 | 固定5,000円→時間単位課金に拡張（Money VO の拡張） |
| 見積・請求書生成                   | 継続案件への対応                               |
| 顧問契約（サブスクリプション）     | Stripe Subscription の追加                     |

| 削除・簡素化できる機能             | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| ブレイクアウトルーム               | 1対1相談が基本なので不要                       |

**市場機会**: 士業のDXは遅れており、特に地方の事務所がオンライン相談を始めたいニーズが強い。

### 4. 企業向け福利厚生・EAP（従業員支援プログラム）

**適合度: ★★★★☆**

企業が従業員にカウンセリング・コーチング・健康相談を提供するBtoBtoCモデル。

| 追加すべき機能                     | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| 企業テナント管理（マルチテナント） | 企業ごとに利用枠・専門家を分離                 |
| 匿名予約                           | メンタルヘルス相談で企業に個人が特定されない仕組み |
| 利用レポート（匿名集計）           | 企業向けの利用状況ダッシュボード               |
| 企業一括決済                       | 個人課金ではなく企業請求書払い                 |
| 利用回数上限                       | 「月3回まで無料」等の制御                      |

| 削除・簡素化できる機能             | 理由                                           |
| ---------------------------------- | ---------------------------------------------- |
| 顧客側の決済フロー全体             | 企業課金のため個人決済は不要                   |
| 顧客情報の詳細管理                 | 匿名性の担保                                   |

**市場機会**: EAP市場は世界的に拡大中。特にメンタルヘルスの企業責任が注目される日本では導入が進んでいる。

## 横断的に検討すべき機能拡張

どの業界に展開するにしても、以下の機能はプラットフォームとしての価値を大きく高める。

| 機能                                 | 効果                                             |
| ------------------------------------ | ------------------------------------------------ |
| **マルチテナント化**                 | 1つのインフラで複数企業にSaaS提供               |
| **料金の柔軟化**                     | 固定5,000円→コンサルタント/プランごとの自由設定 |
| **繰り返し予約**                     | 定期利用者の囲い込み                             |
| **通知チャネル拡張**（LINE, SMS）    | 日本市場ではLINE通知が予約リマインドに効果的     |
| **多言語対応**                       | インバウンド需要、海外展開                       |
| **Google Calendar連携**              | コンサルタントの既存スケジュールとの同期         |
| **レビュー/評価**                    | マーケットプレイス型への発展                     |
| **分析ダッシュボード強化**           | コンサルタント別売上、リピート率、キャンセル率   |

## 推奨する優先順位

現在のシステムからの **改修コストの低さ** と **市場機会の大きさ** を掛け合わせた評価。

| 優先度 | 業界                             | 理由                                                             |
| ------ | -------------------------------- | ---------------------------------------------------------------- |
| **1**  | メンタルヘルス・カウンセリング   | 改修最小。問診票追加だけでほぼ即投入可能                         |
| **2**  | 士業（弁護士・税理士）相談       | 従量課金の追加で対応可能。DX遅れの業界で参入余地大               |
| **3**  | 企業向けEAP                      | マルチテナント化は必要だが、BtoBの高単価モデル                   |
| **4**  | 教育・コーチング                 | 繰り返し予約と回数券の追加で対応。市場規模大                     |
| **5**  | 占い・スピリチュアル             | 分単位課金の追加が必要だが、市場が大きくブルーオーシャン         |

## アーキテクチャ上の強み

現在のDDDアーキテクチャは業界展開に有利な設計になっている。

- **Money VO の拡張性**: 従量課金・サブスク・回数券など多様な料金体系に対応可能
- **PaymentStrategy の Strategy Pattern**: 新しい決済手段の追加が容易
- **Slot / Booking の Aggregate 分離**: 予約ルールの変更がドメイン層で完結
- **Domain Event**: 業界固有のワークフロー（通知、外部連携）をイベント駆動で追加可能
- **Repository Interface**: インフラ層の差し替え（Firestore → RDB等）が可能
