# あなたのみらい予報 占い師利用規約

## 第1章 総則

### 第1条（適用）

1. 本規約は、一般社団法人JKK（以下「当法人」といいます。）が運営するオンライン占いプラットフォーム「あなたのみらい予報」（以下「本サービス」といいます。）において、占い師として鑑定サービスを提供する者の利用条件を定めるものです。
2. 本規約は、本サービスに占い師として登録するすべての者（以下「占い師」といいます。）に適用されるものとし、占い師は、本規約に同意のうえ本サービスを利用するものとします。
3. 当法人は、占い師に対し、必要に応じてガイドライン、運用ルール、鑑定に関する注意事項その他のルール（以下「個別規定等」といいます。）を定めることができるものとします。個別規定等は、本規約の一部を構成するものとします。
4. 本規約の内容と個別規定等の内容が異なる場合は、個別規定等に特段の定めがある場合を除き、個別規定等の定めが優先して適用されるものとします。
5. 利用者（本サービスを通じて鑑定サービスを利用する個人をいいます。）に適用される「あなたのみらい予報利用規約」（以下「利用者規約」といいます。）は、占い師と利用者との関係を理解するうえで前提となるものであり、占い師は利用者規約の内容を確認したうえで本サービスを利用するものとします。

### 第2条（定義）

本規約において使用する用語の意味は、次の各号に定めるとおりとします。

1. 「本サービス」とは、当法人が運営するオンライン占いプラットフォーム「あなたのみらい予報」をいいます。
2. 「占い師」とは、当法人の承認を得て本サービスに登録し、利用者に対して鑑定サービスを提供する者をいいます。
3. 「利用者」とは、利用者規約に同意のうえ、本サービスを利用する個人をいいます。
4. 「鑑定サービス」とは、占い師が利用者に対して提供する占い、助言その他これに付随するサービスをいいます。
5. 「鑑定契約」とは、利用者と占い師との間で成立する鑑定サービスの提供に関する契約をいいます。
6. 「予約」とは、利用者が本サービスを通じて占い師の鑑定サービスの利用を申し込み、当法人所定の方法により確定した状態をいいます。
7. 「鑑定枠」とは、占い師が本サービス上で設定する、予約を受け付ける日時の範囲をいいます。
8. 「占い師アカウント」とは、占い師が本サービスを利用するために登録した利用資格及び利用情報をいいます。
9. 「登録情報」とは、占い師が登録に際して当法人に提供した情報及び利用中に追加又は変更した情報をいいます。
10. 「掲載情報」とは、占い師のプロフィール、鑑定メニュー、料金、紹介文、画像その他本サービス上に掲載される情報をいいます。

### 第3条（当法人と占い師の関係）

1. 占い師は、当法人から独立した事業者として、自己の責任において鑑定サービスを提供するものとします。
2. 本規約は、当法人と占い師との間に雇用関係、労働者派遣関係、代理関係又は組合関係を生じさせるものではありません。
3. 当法人は、鑑定契約の当事者とはならず、鑑定内容、鑑定結果その他占い師が提供するサービスの内容について、利用者に対して保証するものではありません。
4. 占い師は、自己の所得に係る税務申告、社会保険その他自己に適用される法令上の義務を、自己の責任と費用において履行するものとします。

## 第2章 登録

### 第4条（登録）

1. 占い師として本サービスの利用を希望する者は、当法人所定の方法により登録を申請し、当法人の承認を得るものとします。
2. 当法人は、前項の申請について、鑑定の経験、掲載情報の内容、本人確認書類その他当法人が必要と認める事項を審査したうえで、登録の可否を判断します。
3. 当法人は、次の各号のいずれかに該当する場合、登録を承認せず、又は承認後に登録を取り消すことができるものとします。
   1. 申請内容に虚偽、誤記又は記載漏れがある場合
   2. 過去に本規約その他当法人の定める規定に違反したことがある場合
   3. 第17条に定める反社会的勢力に該当し、又は関与している場合
   4. 未成年者、成年被後見人、被保佐人又は被補助人であって、法定代理人等の同意を得ていない場合
   5. その他当法人が登録を適当でないと判断した場合
4. 当法人は、前項の判断の理由について、開示義務を負わないものとします。

### 第5条（登録情報及び掲載情報）

1. 占い師は、登録情報及び掲載情報について、正確かつ最新の内容を維持するものとします。
2. 占い師は、登録情報に変更が生じた場合、遅滞なく本サービス上で変更手続を行うものとします。
3. 当法人は、掲載情報が本規約、法令又は個別規定等に違反すると判断した場合、占い師に対する事前の通知なく、当該掲載情報の修正を求め、又は掲載を停止することができるものとします。
4. 占い師は、掲載情報について、第三者の著作権、商標権、肖像権その他の権利を侵害しないことを保証するものとします。

### 第6条（アカウント管理）

1. 占い師は、占い師アカウントの認証情報を自己の責任において管理し、第三者に開示、貸与、譲渡又は共有してはならないものとします。
2. 占い師アカウントを用いて行われた一切の行為は、当該占い師による行為とみなされるものとします。
3. 占い師は、占い師アカウントの不正利用又はそのおそれを認識した場合、直ちに当法人に通知するものとします。

### 第7条（Zoom連携）

1. 鑑定サービスはオンライン会議システム（Zoom）を用いて実施されるため、占い師は本サービスと自己のZoomアカウントとの連携を行うものとします。
2. 占い師は、Zoomの利用に関して、Zoomの提供事業者が定める利用条件を遵守するものとします。
3. 当法人は、Zoomその他第三者が提供するサービスの仕様変更、障害又は提供終了に起因して鑑定サービスの実施に支障が生じた場合、法令上の責任を負う場合を除き、その責任を負わないものとします。

## 第3章 鑑定サービスの提供

### 第8条（鑑定枠の設定）

1. 占い師は、本サービス上で鑑定枠を設定し、随時これを追加、変更又は削除することができるものとします。
2. 占い師は、予約が成立した鑑定枠について、第10条に定める場合を除き、これを取り消すことができないものとします。
3. 占い師は、実際に鑑定サービスを提供できる日時のみを鑑定枠として設定するものとします。

### 第9条（鑑定の実施）

1. 占い師は、予約が成立した鑑定について、予約された日時に鑑定サービスを提供するものとします。
2. 占い師は、鑑定開始時刻までにオンライン会議システムに接続し、利用者を待機させないよう努めるものとします。
3. 利用者が予約時間に参加しない場合、占い師は予約時間から予定終了時間まで待機するものとします。予定終了時間を過ぎても利用者が参加しない場合、占い師は鑑定を終了することができるものとします。
4. 占い師は、利用者に対し、誠実かつ丁重に対応するものとし、利用者の尊厳を害する言動を行ってはならないものとします。
5. 占い師は、当法人又は利用者の事前承諾なく、鑑定内容の録音、録画、撮影又は第三者への配信を行ってはならないものとします。

### 第10条（占い師都合による変更・欠席）

1. 占い師は、疾病、事故その他やむを得ない事由により鑑定サービスを提供できない場合、可能な限り速やかに当法人に連絡するものとします。
2. 前項の場合、当法人は、利用者への連絡、日程の再調整、利用料金の返金その他必要な措置を講じることができるものとします。
3. 占い師が正当な理由なく鑑定サービスを提供しなかった場合、当法人は、第23条に定める利用制限その他必要な措置を講じることができるものとします。

### 第11条（通信障害）

1. 鑑定中に通信障害その他の事由により鑑定を継続できなくなった場合、占い師は、当法人所定の方法により速やかに当法人に報告するものとします。
2. 前項の場合の取扱いは、当法人が利用者及び占い師の状況を確認したうえで決定するものとします。

## 第4章 料金・報酬

### 第12条（鑑定料金の設定）

1. 利用者が支払う利用料金は、当法人が定める料金体系の範囲内で、当法人又は占い師が本サービス上に設定するものとします。
2. 利用料金の徴収は当法人が利用者から行い、占い師は利用者から直接に利用料金を受領してはならないものとします。

### 第13条（報酬）

1. 当法人は、占い師に対し、成立した鑑定契約に基づき提供された鑑定サービスの対価として、報酬を支払うものとします。
2. 報酬の額、算定方法、当法人が収受する手数料の割合、締め日、支払期日及び支払方法は、【要確認：報酬体系・手数料率・締め日・支払サイクル・振込手数料の負担を確定し記載してください】のとおりとします。
3. 占い師は、報酬の受領に必要な口座情報その他の情報を、当法人所定の方法により正確に届け出るものとします。届出内容の誤りにより生じた支払遅延又は不着について、当法人は責任を負わないものとします。
4. 当法人は、占い師に対して債権を有する場合、報酬から当該債権額を控除して支払うことができるものとします。

### 第14条（返金が生じた場合の取扱い）

1. 利用者に対する利用料金の返金が生じた場合、当該鑑定に係る報酬は発生しないものとし、既に支払済みの場合は、当法人は次回以降の報酬から控除し、又は返還を求めることができるものとします。
2. 前項の取扱いの詳細は、利用者向けキャンセルポリシー及び個別規定等の定めによるものとします。

## 第5章 禁止事項

### 第15条（占い師の禁止行為）

占い師は、本サービスの利用にあたり、次の各号に掲げる行為を行ってはならないものとします。

1. 法令又は公序良俗に違反する行為
2. 当法人、利用者又は第三者の権利、利益又は名誉を侵害する行為
3. 経歴、資格、実績その他掲載情報について虚偽の内容を表示する行為
4. 利用者に対し、鑑定結果の実現、開運、病気の治癒その他の効果を保証する表示又は説明を行う行為
5. 利用者の不安をあおり、又は威圧して、追加の鑑定、物品若しくは役務の購入を勧誘する行為
6. 医療、法律、税務その他の資格を要する行為を、資格を有しないまま行う行為
7. 利用者に対する差別的言動、性的な言動、つきまとい行為その他のハラスメント行為
8. 第16条に定める直接取引又はその勧誘
9. 本サービスの運営を妨害し、又は本サービスの信用を毀損する行為
10. 本サービスを通じて知り得た情報を、鑑定サービスの提供以外の目的に利用する行為
11. 前各号に準ずる行為として当法人が不適当と判断する行為

### 第16条（直接取引の禁止）

1. 占い師は、本サービスを通じて知り合った利用者との間で、本サービスを経由しない鑑定サービスの提供及びその対価の授受（以下「直接取引」といいます。）を行ってはならないものとします。
2. 占い師は、利用者に対し、自己又は第三者の連絡先、SNSアカウント、決済手段その他直接取引を誘引する情報を提供してはならないものとします。
3. 占い師が前二項に違反した場合、当法人は、第23条に定める利用制限その他必要な措置を講じることができるものとします。

### 第17条（反社会的勢力の排除）

1. 占い師は、現在及び将来にわたり、暴力団、暴力団員、暴力団準構成員、暴力団関係企業、総会屋、社会運動等標ぼうゴロ、特殊知能暴力集団その他これらに準ずる者（以下「反社会的勢力」といいます。）に該当しないことを表明し、保証するものとします。
2. 占い師は、自ら又は第三者を利用して、暴力的行為、法的責任を超えた不当な要求、脅迫的言動、風説の流布その他これらに準ずる行為を行わないものとします。
3. 占い師が前二項に違反した場合、当法人は、事前の通知なく登録を取り消すことができるものとします。この場合、当法人は、占い師に生じた損害について責任を負わないものとします。

## 第6章 秘密保持・個人情報

### 第18条（秘密保持）

1. 占い師は、本サービスの利用に際して知り得た利用者の相談内容、身上に関する情報、当法人の営業上又は技術上の情報その他秘密として取り扱うべき情報を、第三者に開示又は漏洩してはならないものとします。
2. 前項の義務は、占い師が本サービスの利用を終了した後も存続するものとします。
3. 占い師は、法令に基づく開示要請を受けた場合、可能な範囲で事前に当法人に通知するものとします。

### 第19条（個人情報の取扱い）

1. 占い師は、本サービスを通じて取得した利用者の個人情報を、鑑定サービスの提供の目的に限り取り扱うものとします。
2. 占い師は、前項の個人情報について、漏洩、滅失又は毀損を防止するために必要な安全管理措置を講じるものとします。
3. 占い師自身の個人情報の取扱いについては、「あなたのみらい予報 占い師プライバシーポリシー」の定めによるものとします。

### 第20条（知的財産権）

1. 本サービス及び本サービスに関して当法人が提供するコンテンツに関する知的財産権は、当法人又は正当な権利者に帰属するものとします。
2. 占い師は、掲載情報について、当法人が本サービスの運営、広告及び宣伝の目的で無償かつ非独占的に利用（複製、改変、公衆送信及び翻案を含みます。）することを許諾するものとします。
3. 前項の許諾は、占い師が本サービスの利用を終了した後も、当法人が既に作成した広告物等に関する範囲で存続するものとします。

## 第7章 サービス運営

### 第21条（サービスの変更）

当法人は、本サービスの全部又は一部について、追加、変更、中断又は終了することができるものとします。当法人は、占い師の鑑定枠又は成立済みの予約に重大な影響を及ぼす変更を行う場合、あらかじめ相当な期間をおいて通知するよう努めます。

### 第22条（サービスの停止）

1. 当法人は、次の各号のいずれかに該当する場合、占い師に対する事前の通知なく、本サービスの全部又は一部の提供を停止又は中断することができるものとします。
   1. 本サービスに係る設備の保守、点検又は更新を行う場合
   2. 火災、停電、天災地変その他の不可抗力により本サービスの提供が困難となった場合
   3. 通信回線、外部サービスその他第三者の提供する設備又は役務に障害が生じた場合
   4. その他当法人が停止又は中断を必要と判断した場合
2. 当法人は、前項の措置により占い師に生じた損害について、法令上の責任を負う場合を除き、責任を負わないものとします。

### 第23条（利用制限）

1. 当法人は、占い師が次の各号のいずれかに該当する場合、事前の通知なく、掲載情報の非表示、鑑定枠の受付停止、占い師アカウントの一時停止又は登録の取消しその他必要な措置を講じることができるものとします。
   1. 本規約又は個別規定等に違反した場合
   2. 登録情報又は掲載情報に虚偽があることが判明した場合
   3. 利用者からの申告その他の事情により、鑑定サービスの品質又は安全性に重大な疑義が生じた場合
   4. 正当な理由なく鑑定サービスを提供しなかった場合
   5. その他当法人が本サービスの運営上不適当と判断した場合
2. 当法人は、前項の措置により占い師に生じた損害について、責任を負わないものとします。

### 第24条（登録の抹消）

1. 占い師は、当法人所定の方法により、本サービスの利用を終了し、登録の抹消を申請することができるものとします。
2. 占い師は、成立済みの予約がある場合、当該鑑定サービスの提供を完了した後に前項の申請を行うものとします。
3. 登録の抹消後も、既に発生した報酬請求権及び本規約上の義務（第18条、第20条第3項及び第27条を含みます。）は存続するものとします。

## 第8章 免責

### 第25条（利用者とのトラブル）

1. 占い師と利用者との間で生じた紛争は、占い師と利用者との間で解決するものとします。
2. 当法人は、前項の紛争について、法令上又は本規約上別段の定めがある場合を除き、その解決義務を負わないものとします。ただし、当法人は、本サービスの円滑な運営のため、必要と認める範囲で協議又は調整に協力することができます。

### 第26条（損害賠償の制限）

1. 当法人が占い師に対して負う損害賠償責任の範囲は、当法人の故意又は重大な過失によるものを除き、当該損害の直接の原因となった鑑定に係る報酬額を上限とします。
2. 当法人は、占い師に生じた逸失利益、機会損失その他の間接損害及び特別損害について、責任を負わないものとします。
3. 本条の規定は、占い師が消費者契約法上の消費者に該当する場合において同法により無効となる範囲では適用されないものとします。

### 第27条（占い師の責任）

1. 占い師は、本規約に違反し、又は自己の責めに帰すべき事由により当法人、利用者又は第三者に損害を与えた場合、その損害を賠償する責任を負うものとします。
2. 占い師の行為に起因して当法人が第三者から請求を受けた場合、占い師は、当法人が支出した費用（合理的な弁護士費用を含みます。）を負担するものとします。

## 第9章 一般条項

### 第28条（規約変更）

1. 当法人は、法令の改正、本サービスの内容変更、運営上の必要その他合理的な理由がある場合、本規約を変更することができるものとします。
2. 当法人は、本規約を変更する場合、変更後の内容及び効力発生日を、本サービス上への掲載その他当法人が適当と認める方法により周知します。
